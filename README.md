# Seguridad Alimentaria al Día

App (PWA) bilingüe de **Vibras Positivas HM** sobre seguridad alimentaria en Colombia y el Bajo Cauca.

- **Hoy**: búsqueda en vivo al abrir + noticias reales que trae el robot cada 30 minutos (GitHub Actions).
- **Cifras**: DANE-FIES 2025 por departamento, los 5 ejes de la seguridad alimentaria.
- **Mi hogar**: test FIES de 8 preguntas (privado) y calculadora del mercado con el salario mínimo 2026.
- **Plato que rinde**, **Huerta casera** para clima cálido, **Campo y abastecimiento**, **Programas**.
- **Veeduría y derecho de petición**: se envía de una sola vez a todas las entidades.
- Fotos y videos reales de Wikimedia Commons; vista previa del enlace (`img/og.jpg`) renovada por el robot.

Publicación: Netlify → `seguridad-alimentaria.netlify.app` (publish = raíz).
Para renovar fotos ya: Actions → *Robot de Seguridad Alimentaria* → Run workflow → fotos = 1.
